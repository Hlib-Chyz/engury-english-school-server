# 🛠️ Engury English School - Server

A backend application for the **Engury English School** platform, built with **NestJS**.  
It supports features like managing courses, submitting reviews, and more.  
The main focus was on integration with **AWS S3**, **sending emails with Nodemailer**, and **writing unit tests**.

## 🔧 Technologies Used

- **NestJS**
- **Mongoose**
- **AWS SDK / AWS S3**
- **Nodemailer**
- **Unit Testing (e.g., Jest)**
- **MongoDB**
